## 1. 从截图提炼的设计语法（借什么 / 不借什么）

三张图：达·芬奇工房（商店）、终端（主菜单）、终端（召唤）。它们的共同结构：

| # | 语法 | 截图里的表现 | 在 DSH 里怎么落 | 是否需要美术素材 |
|---|---|---|---|---|
| G1 | **顶栏状态条** | 左上"关闭/通知"、中间资源数字、右上设施名 + 小号英文副标题 | `conversation.header` 区域着色 + 字重/字距；`shell.bottom` 放常驻状态条 | 否（CSS） |
| G2 | **金色双层描边框** | 外框金线、内层白玻璃、四角装饰 | `border` + `box-shadow: inset` + 自绘 SVG 角饰 | 否（自绘） |
| G3 | **半透明白玻璃面板** | 按钮/卡片都是白玻璃 + 蓝色高光边 | token 半透明 + `backdrop-filter: blur()` | 否 |
| G4 | **菱形图标底板 + 单色符号** | 菜单项左端菱形、底部 dock 一排菱形 | 自绘 SVG（`clip-path: polygon` 或 `<path>`）+ 图标替换 | 否（自绘） |
| G5 | **中文粗标题 + 大写衬线英文副标** | 「灵基变还 / Burning」 | `--bj-font-display`（衬线）+ `letter-spacing` 小字 | 否（字体 OFL） |
| G6 | **深海军蓝菱格底纹** | 页面上下边缘的深蓝暗纹 | CSS `repeating-linear-gradient` 交织或 SVG pattern | 否 |
| G7 | **右对齐长条主按钮 + 右下主操作** | 右侧列表按钮、右下「菜单」 | 只改颜色/描边/圆角，**不改结构** | 否 |

**不借**：角色立绘、游戏图标、Logo、任何游戏内素材（TYPE-MOON 保留所有权利）。
**结论**：截图给的是**版式语言与材质配方**，用 CSS/SVG 可 100% 复刻"味道"，不需要任何版权素材。

> 因此默认主题 = 深色（`#0d1117` 系基底 + 金色 `#c8a24a` 描边/强调 + 白玻璃面板 + 菱格底纹），
> 浅色版由同一套派生逻辑生成（纸白 + 暗金），两套共用一份配置。

## 2. 模块矩阵（你列的 10 类，逐项落位）

| # | 模块 | 落点（slot / 接口） | 借谁 | 版本 | 验收 | 风险 |
|---|---|---|---|---|---|---|
| **M1** | 覆盖层 / 全屏浮层 | `shell.overlay`、`shell.bottom` | startup-screen、bloom | v1.5 | 可开关；卸载无残留；不遮输入框 | z-index / pointer-events 干扰 |
| **M2** | 输入框 dock 组件 | `conversation.input.dock`、`.left`、`.right` | 官方模板、多个主题 | v1.5 | 窄窗 980×640 不挤压输入 | slot 曾改名 |
| **M3** | 品牌标 / 字标替换 | `sidebar.brand.mark`、`conversation.hero.brand.mark` | endfield、rhine-splash | **v1.3** | 明暗两套；替换后布局不位移 | 需自绘 SVG，避免商标 |
| **M4** | 设置页新分区 | `settings.*`（theme-pack 用 `settings.section`） | theme-pack、catppuccin | v1.4（只读卡）→ v1.6（可交互） | 设置项持久化、重启保持 | settings API 换过代 |
| **M5** | 图标整套替换 | `theme` 服务 icon 接口（限 `ICON_SYMBOLS`） | 无公开成品（接口实测存在） | v1.4 | 12–20 个高频图标无破图、无位移 | 未知 id 被拒；SVG 规范严格 |
| **M6** | 壁纸 / 视频 / 玻璃材质 | L3 背景层 + token 半透明 + `backdrop-filter` | video-skin、open-sea、transparent-ui、any-background | v1.6 | 关闭后完全恢复；不卡帧；减动效 | 性能、与 token 透明度冲突 |
| **M7** | 主题包 / 皮肤中心 | 自有 `skin.json` + 列表 UI（overlay 或设置分区） | **dsh-skins**（BSD-3） | v1.6 | 导入/导出/切换幂等；坏包回退 | 格式演进、与官方主题列表冲突 |
| **M8** | 安全模式 / 失败回滚 | 配置校验失败回退默认 + 一键停用 | dsh-theme-plugin | v1.6 | 故意写坏配置，界面仍可用 | 需宿主不崩 |
| **M9** | 开屏（跨端优先） | 优先 `shell.overlay` 正片；web 额外用 `webserver/index-inject` 抢首帧 | boot-suite、550c-boot、video-skin | v1.6 | 三路退出、刷新去重、减动效 | 桌面首帧机制未验 |
| **M10** | Agent 侧能力 | `ctx.skills.registerProvider` | 无成熟先例 | v1.7（可选） | 技能可见、可被调用 | 契约未确认 |

> M3 提前到 v1.3：字标是"这是不是一套主题"的第一眼证据，成本低、收益高。
> M4 拆两半：先放只读信息卡（零风险），可交互设置放 v1.6 与安全模式一起做。

## 3. 能力分层（保留 v1 的分法，压缩）

| 层 | 内容 | 手段 | 复用 |
|---|---|---|---|
| L1 颜色 | 133 token（123 alias + 10 specific），明暗双套 | `overrideTokens` + 逐个验证消费点 | theme-pack 129/129、catppuccin |
| L2 区块 | 侧栏 / 输入区 / 消息卡 / 代码块 / 按钮 / 弹层 | 只用 `data-slot` 与稳定 `data-*` 锚点；禁哈希类 | dsh-skins 的 L1/L2 契约、any-background |
| L3 密度 | 字号/行高/圆角/描边/阴影 | 88 个 `--dsh-*` + 自有 `--bj-*` | endfield（直角/圆角）、bloom（材质） |
| L4 覆盖层 | M1/M2/M3/M5/M6/M9 | slot + client | bafx、video-skin、wallpaper-engine |
| L5 系统级（可选） | 真桌宠窗口、WE 场景渲染、音频子进程、标题栏透明 | host 侧 Electron/子进程 | dsh-pet、wallpaper-engine、startup-screen |

**桌面端**：L1–L4 全部同一套 client（bafx 已验证"Web 与桌面同一实现"）；仅"首帧注入"待实测，真桌宠/音频属系统级。

## 6. 明确不做

1. 布局重排（三栏结构、面板顺序、`root` slot）。
2. 前端路由 / 新页面（只加 HTTP 路由）。
3. 组件交互逻辑改写。
4. 窗口外框与原生菜单（除桌面标题栏透明这类特例，需单独评估）。
5. 任何 FGO 美术资产入包（立绘、图标、Logo、字体子集以外的东西）。
6. 正面重建宠物 / 壁纸引擎 / 开屏生态。

## 7. 风险与对策

| 风险 | 对策 |
|---|---|
| L2 选择器随构建碎 | 只用 `data-slot` / `data-*`；集中在 `overrides.tier3.css`，文件头写验证版本 |
| token 写了不生效 | 每个 token 必须找到消费元素，否则标"未消费"不写进主题 |
| 桌面首帧未知 | v1.3 先把桌面跑通；v1.6 开屏以 client overlay 为主，index-inject 作增强 |
| settings API 换过代 | M4 先只读；可交互部分与 M8 一起做，失败可回退 |
| 体积与性能（壁纸/玻璃） | 默认关闭，开启需显式配置；减动效与低配设备降级 |
| DSH 版本快（1.77 天/版） | 窄接缝 + 每版兼容检查 + 超范围由宿主跳过 |
