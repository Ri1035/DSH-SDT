# 全局主题 / 菜单可点 / 桌宠尺寸 —— 计划（2026-11-25）

## 一、问题与根因（已实测定位）

| # | 现象 | 根因 |
|---|---|---|
| 1 | 侧栏列表里「◆ DSH-SDT」点文字没反应，只有 16px 图标能点 | 宿主把每个面板项包在 `<button class="…panelRow">` 里，我们的小按钮嵌在内层；行内文字区域属于宿主按钮，点了没有任何动作 |
| 2 | 设置页 / 开始页 / 右栏 / 插件页仍是浅色实底，只有聊天区有视频 | 壁纸清底只处理了 `main` 锚点；这些页面是**独立表面**，各有不透明底色（`rgb(238,246,251)`），且不读我们覆盖的那几个 bg token |
| 3 | 控制台 `/sdt/console` 点不动 | 待复核：先在宿主 web 端口用 CDP 实点，确认是脚本未绑定还是窗口行为 |
| 4 | 桌宠大小只能改配置文件 | 没有 UI 入口 |

## 二、方案

### A. 菜单整行可点
- 组件从 `<button>` 改为 `<span data-sdt-menu>`（避免嵌套按钮）；
- 文档级 capture 监听：命中「包含 `[data-sdt-menu]` 的最近 `button`」整行 → 打开面板；
- 保留键盘可达（宿主行本身是 button）。

### B. 主题全局（统一玻璃）
- 不再按 `data-slot` 清底，改为**几何 + 不透明度**扫描：
  - 面积 ≥ 20% 视口、背景 alpha ≥ 0.95 的容器 → 打 `data-sdt-glass`；
  - 只对「页面级」容器（fixed / body 或 #root 直系）加 `z-index:1`，避免破坏层叠；
- `[data-sdt-glass]` 统一为 `bg-l1 72% + blur(18px)`；侧栏同步降到 72%，让视频明显透出；
- 3s 重扫（React 会重建节点），页面隐藏时跳过；关闭壁纸时全部移除。

### C. 桌宠尺寸
- 滚轮悬停缩放（120–420，步进 12），指针样式提示；
- 面板「状态」页加滑杆（同范围），实时生效；
- 尺寸写 `localStorage`（`sdt-pet-size`），配置 `pet.size` 作默认值。

### D. 控制台点击
- 用宿主 web 端口 + CDP 实点三个页签与卡片，定位是脚本还是窗口问题；若是脚本，补事件绑定兜底。

## 三、验收

| 项 | 标准 |
|---|---|
| 菜单 | 点行内文字、图标都能开面板；Esc 关闭 |
| 设置页 | 背景透出视频，卡片仍可读 |
| 开始页 | 同上，四张工具卡不透明可读 |
| 右栏 | 同上 |
| 桌宠 | 滚轮/滑杆都能改，刷新后保持 |
| 控制台 | 三个页签切换有反应 |
| 回归 | 980×640 无溢出；reduced-motion 不炸；8/8 |

## 四、暂不做（记录）

- 「背景 / UI / 组件」三部分独立换肤（用户提过，留 v2.1）；
- Live2D 桌宠（等 Cubism 运行时目录）；
- 壁纸暗色模式联动（先统一为浅色玻璃，观感不满意再切）。
