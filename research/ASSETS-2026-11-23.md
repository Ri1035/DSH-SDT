# 公开 FGO 素材源清单（2026-11-23）

> 用途：给 DSH-SDT 的**静态样张**与后续默认灵衣提供素材来源，并明确**哪些能入库、哪些只能本地用**。

## 0. 三句话结论

1. **FGO 游戏美术（立绘、灵衣、模型、UI 图标、语音）版权属于 TYPE-MOON / FGO PROJECT，全部权利保留** —— 可以本地做 demo，**不能打包进插件分发**。
2. **Mooncell 是可用素材仓库**：站点文字/整理内容 CC BY-NC-SA 4.0；游戏图片另行声明为 TM 所有。用它的 MediaWiki API 可以批量取图，但取到的是"有版权的图"。
3. **能安全入库的只有三类**：开源字体、开源图标、自生成纹理/自绘 SVG。所以插件本体必须"自带干净素材 + 用户自备 FGO 素材"，这也是我们"素材可替换"设计的合法性基础。

## 2. 素材源清单

### A. Mooncell（fgo.wiki）—— 主素材库

| 项 | 内容 |
|---|---|
| 站点 | https://fgo.wiki |
| 能取什么 | 灵衣模型图、从者立绘、礼装、道具、图标、活动图 |
| 取法【实测】 | MediaWiki API：`api.php?action=query&list=search&srnamespace=6&srsearch=灵衣` → 得到 `文件:…` 列表 → `prop=imageinfo&iiprop=url` 拿直链 |
| 实测样例 | `文件:英灵模型160 灵衣.png` → `https://media.fgo.wiki/5/50/…png`，**600×600 PNG** |
| 授权 | 游戏图 TM；站点内容 CC BY-NC-SA 4.0 |
| 建议 | 本地 demo 用；demo 页脚必须写「图片来源：Mooncell / TYPE-MOON」；**不下载入库** |

### B. Atlas Academy（atlasacademy）—— 结构化数据 + 静态图床【实测可用】

| 建议 | 批量取图做 demo；`/nice/JP/costume/{id}` 端点实测 **404**，灵衣数据走 `export/JP/nice_costume.json` |

## 3. 授权红线（写进项目纪律）

1. **插件包内不得出现任何 TYPE-MOON 美术** —— 包括灵衣图、卡面、模型、UI 图标、语音。
2. **demo/截图可以出现**，但必须：① 仅本地；② 页脚署名「图片来源：Mooncell / Atlas Academy，版权属 TYPE-MOON / FGO PROJECT」；③ README 里只放**不含游戏素材**的自制示意图。
3. **文案引用 Mooncell 数据**要署名 + 链接，且不能声称是"官方数据"。
4. **字体/图标必须保留原许可文件**（OFL 要求随分发附许可文本）。

## 4. 我推荐给静态样张的素材组合（8 项）

| # | 素材 | 来源 | 用途 |
|---|---|---|---|
| 1 | 灵衣立绘 1 张（如「亚瑟·潘德拉贡灵衣」） | Mooncell | 样张右上角「当前灵衣」卡片 |
| 2 | 从者卡面 1 张（charaGraph） | Atlas | 侧栏底部角色位 |
| 3 | 5 色主色板 | **从 1 号图自动取色**（Pillow 聚类） | 生成 `--bj-*` 色阶，demo 与 v1.2 共用 |
| 4 | 细线纸纹 | CSS 自生成 | 面板底纹 |
| 5 | 描边角标 4 个 | Lucide（ISC） | 卡片四角 HUD |
| 6 | 标题字体 | 思源宋体子集（OFL） | 一级标题 |
| 7 | 分隔纹样 | 自绘 SVG（缝线/纽扣） | 区块分隔 |
| 8 | 状态徽标 | 自绘 SVG | 「已缝制 / 未缝制 / 可切换」 |

> 这套的逻辑是：**颜色从素材里长出来**，不是拍脑袋定的色板 —— 这正好是"缝制"的工程化表达，也能自动适配你以后丢进来的任何灵衣图。

## 5. 采集操作（可复现命令）

```bash
# Mooncell：搜文件 → 拿直链（实测可用）
curl "https://fgo.wiki/api.php?action=query&format=json&list=search&srnamespace=6&srlimit=20&srsearch=灵衣"

# Atlas：直接取立绘（实测 497 KB PNG）
curl -o chara.png "https://static.atlasacademy.io/JP/CharaGraph/100100/100100a@1.png"

# 取色（本地，Pillow）
python -c "from PIL import Image; im=Image.open('chara.png'); print(im.convert('RGB').resize((80,80)).getcolors(6400)[:8])"
```

> 下载目录：`demo/assets/`（**已 git 忽略**，只作本地样张用）。
