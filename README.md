## 项目简介

Boujoy Harness 是一个装上即带完整外观的 DSH 主题插件，同时保留一套可自定义框架，让想改成自己风格的人有发挥空间。它不修改 DSH 任何核心源码，而是通过 DSH 官方的 Cordis 插件体系（bundle + slot 系统 + theme token）实现对界面的改造。默认主题装上去就是一套完整的 Boujoy 外观，零操作、无需阅读文档。

核心设计是**引擎与内容分离**：代码只负责渲染，外观素材全部放在用户数据目录里；插件升级不覆盖用户内容，卸载也不删除。

## 主要功能

- **开屏动画**：从应用启动到界面就绪的完整片头，不露出 DSH 自带的 Loading 卡片
- **风格界面**：品牌配色、字体、字标、背景氛围、圆角与材质
- **对话动画**：助手消息入场、流式输出节奏、工具卡片缓动
- **素材可替换**：把图片/字体等素材丢进素材目录，由随插件分发的 Agent 技能自动适配成一套新外观；无需了解槽位命名、无需手写配置
- 高度自定义能力矩阵共 12 项，其中多数零代码即可完成

## 使用方法

> 本项目处于规划与调研阶段，尚未提供可安装产物；以下为目标形态。

目标形态下，一条命令安装插件后正常启动 DSH，默认即为完整 Boujoy 外观。想换成自己风格时，把素材文件放进插件素材目录，再让 Agent 用这些素材配置一套外观即可，产物与配置文件由 Agent 自动生成。

## 技术栈

- 基于 DSH 官方 Cordis 插件体系（bundle / slot / theme token）
- CSS（自定义属性 token、动画）
- 随插件分发的 Agent 自定义适配技能（Skill）
